NHITW 診間報告產生器 — 安裝與更新教學

查健保雲端的同時，自動幫每位病人產生一頁 HTML 報告存進共享資料夾；診間電腦不用裝任何東西，點開檔案就能看。

📦 這個壓縮包裡有什麼
資料夾 / 檔案用途
dist/Chrome / Edge 擴充套件本體（載入未封裝項目時選這個資料夾）
native-host/共享資料夾主機（雙擊裡面的 install.bat 安裝）
README.html本說明

🚀 全新安裝（第一次裝，約 10 分鐘）

事前準備：一個櫃檯和診間都開得到的共享資料夾（NAS、伺服器、或任一台電腦分享出來的資料夾），例如 \\你的伺服器\共享\Chart。以下都在櫃檯（讀卡查雲端）的電腦操作。

  1. 解壓縮後會得到一個 reader 資料夾，把它放到固定位置，例如 C:\reader（之後不能刪、不能搬家）
  2. 打開 Chrome，網址列輸入 chrome://extensions（Edge 輸入 edge://extensions）
  3. 打開右上角「開發人員模式」
  4. 點「載入未封裝項目」→ 選 C:\reader\dist 資料夾
  5. 進 C:\reader\native-host，雙擊 install.bat：
    • Enter shared folder path → 輸入你們院所的共享資料夾路徑後按 Enter
    • Enter Chrome extension ID → 直接按 Enter（預設值就是正確的，所有院所都相同）
  6. 完全關閉 Chrome 再重開（右上角選單 → 結束，不是只關視窗）
  7. 點擴充套件圖示 → 設定 → 打開「啟用自動匯出」→ 按「檢查連線」顯示正常即完成
驗收：刷一張健保卡查雲端，約 10 秒後共享資料夾出現 今天日期\早診(午診/晚診)\病人姓名_時間.html，診間點開就能看。

🔄 日常更新（醫師自己 30 秒完成）

  1. 下載最新完整包（固定網址，永遠是最新版）：
    https://github.com/jeff830621/NHITW_clinic_reader/raw/release/releases/NHITW_clinic_reader_latest.zip
  2. 解壓縮，用解壓出的 reader 資料夾內容覆蓋原本的安裝位置（例如 C:\reader，全部取代）
  3. 回到 chrome://extensions，在本套件卡片上按「重新整理 ↻」圖示
  4. （只有公告特別提到「主機有更新」時才需要：進 native-host 重跑一次 install.bat，兩個問題都直接 Enter）
⚠ 從舊版包（解壓後 manifest.json 直接在根目錄的版本）第一次換到本版時：
  1. 在 chrome://extensions 先「移除」舊的套件
  2. 刪掉舊資料夾內容，重新解壓本包
  3. 「載入未封裝項目」改選 dist 資料夾
  4. 之後的更新就照上面的 30 秒流程即可

❓ 常見問題

狀況處理方式
查了雲端但共享資料夾沒報告設定裡「啟用自動匯出」要開、「檢查連線」要正常；install.bat 輸入的路徑要正確；Chrome 要完全重啟過
擴充套件圖示出現紅色 ⚠上一次匯出失敗（共享資料夾斷線 / 主機未裝 / 報告過大）。排除後再查一次即可
報告保留幾天？預設 40 天後自動清除；天數在設定頁「資料保留天數」調整（1–90）
有多台讀卡電腦每台都做「全新安裝」步驟（共享資料夾路徑輸入同一個）
想移除執行 native-host\uninstall.bat，並在 chrome://extensions 移除套件
