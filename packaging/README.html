NHITW 診間報告產生器 — 安裝與更新教學

查健保雲端的同時，自動幫每位病人產生一頁 HTML 報告存進共享資料夾；診間電腦不用裝任何東西，點開檔案就能看。

📦 這個壓縮包裡有什麼
資料夾 / 檔案用途
native-host/共享資料夾主機（雙擊裡面的 install.bat 安裝）— 每台讀卡電腦都要裝
dist/擴充套件本體 — 一般不需要用到（擴充套件請從商店安裝，見下方）；只給無法使用商店的情況備用
README.html本說明

🚀 全新安裝（第一次裝，約 5 分鐘）

事前準備：一個櫃檯和診間都開得到的共享資料夾（NAS、伺服器、或任一台電腦分享出來的資料夾），例如 \\你的伺服器\共享\Chart。以下都在櫃檯（讀卡查雲端）的電腦、用 Microsoft Edge 操作。

  1. 用 Edge 打開商店頁面，按「取得」安裝擴充套件：
    https://microsoftedge.microsoft.com/addons/detail/ffopjenekhkampkfckmbegbglnebhjib
  2. 解壓本壓縮包，進 native-host 資料夾，雙擊 install.bat：
    Enter shared folder path → 輸入你們院所的共享資料夾路徑後按 Enter（只有這一題）
  3. 完全關閉 Edge 再重開（右上角選單 → 結束，不是只關視窗）
  4. 點擴充套件圖示 → 設定 → 打開「啟用自動匯出」→ 按「檢查連線」顯示正常即完成
驗收：刷一張健保卡查雲端，約 10 秒後共享資料夾出現 今天日期\早診(午診/晚診)\病人姓名_時間.html，診間點開就能看。

🔄 日常更新：不用做任何事

擴充套件由 Edge 商店自動更新，Edge 會定期自行檢查並安裝新版，醫師和櫃檯都不需要操作。（想立刻更新：edge://extensions → 開啟左下角「開發人員模式」→ 按「更新」）

只有公告特別提到「主機有更新」時，才需要下載最新主機包重跑一次 install.bat（直接 Enter 即可，會自動帶入原本的共享資料夾路徑）：
https://github.com/jeff830621/NHITW_clinic_reader/raw/release/releases/NHITW_clinic_reader_host_latest.zip

⚠ 原本用「載入未封裝項目」方式安裝的院所，換到商店版（一次性，約 3 分鐘）：
  1. 用 Edge 打開上面的商店頁面，按「取得」安裝
  2. 用本包的 native-host\install.bat 重跑一次（直接 Enter）— 這步一定要做，否則商店版連不上共享資料夾
  3. 點新裝的擴充套件圖示 → 設定 → 重新打開「啟用自動匯出」（若保留天數原本不是 40 也要重設）→ 按「檢查連線」
  4. 到 edge://extensions 移除舊的（未封裝）套件 — 兩個同時開著會產出兩份報告

❓ 常見問題

狀況處理方式
查了雲端但共享資料夾沒報告設定裡「啟用自動匯出」要開、「檢查連線」要正常；install.bat 輸入的路徑要正確；Edge 要完全重啟過
擴充套件圖示出現紅色 ⚠上一次匯出失敗（共享資料夾斷線 / 主機未裝 / 報告過大）。排除後再查一次即可
報告保留幾天？預設 40 天後自動清除；天數在設定頁「資料保留天數」調整（1–90）
有多台讀卡電腦每台都做「全新安裝」步驟（共享資料夾路徑輸入同一個）
沒有共享資料夾、只有一台電腦設定 → 匯出方式改選「瀏覽器下載」，報告會存到 Edge 下載資料夾的 NHITW_reports（不用裝主機，但不含自動清理）
只能用 Chrome、無法用 Edge用本包的 dist 資料夾：chrome://extensions → 開發人員模式 → 載入未封裝項目 → 選 dist；其餘步驟相同（此方式不會自動更新）
想移除執行 native-host\uninstall.bat，並在 edge://extensions 移除套件
